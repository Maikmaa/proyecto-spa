# Proyecto SPA

## Cliente
Proyecto de sitio web para un SPA. El nombre comercial está pendiente de definir.

## Alcance del sitio
El proyecto consiste en desarrollar un sitio web para el SPA. El diseño contempla una paleta de colores, tipografía, espaciado y componentes de interfaz definidos en el sistema de diseño del proyecto.

## Estado actual
El repositorio está creado y contiene una página inicial de presentación y el archivo `sistema-diseno.md`. El sitio se encuentra en etapa inicial de desarrollo.
